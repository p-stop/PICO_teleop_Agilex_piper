# ADR-0003：图形界面复用图 schema 与 session API

日期：2026-10-11。状态：设计决定，低优先级，未选前端技术栈。

## 背景

研究者需要图形化配置与节点连接，但核心尚无实现。另做 GUI 专属配置和设备命令通道会造成行为分歧。

## 决定

- YAML/JSON 是任务图的持久化表示；GUI 是同一 schema 的编辑与运行客户端。
- 节点位置、颜色、分组等只存 editor metadata，不进入执行语义 hash；设备身份、边、配置、校准与 motion profile 进入语义 hash。
- 前端与 CLI 共用后端 validator/compiler/session API。浏览器校验只辅助，部署前由目标主机再次 probe 和预检。
- 分开数据流图、frame/安装图、host/资源部署视图；连接端口不自动推断变换或赋予控制权。
- 首先只读运行面板，再配置表单、再节点编辑器。运行时修改先生成 diff 并停到可重配置状态，不在拖线时热改物理命令路径。
- UI 提供软件 stop/接管入口；硬件急停和设备本机 watchdog 独立存在。

## 后果与替代方案

CLI 可先交付，后加前端不需要重写驱动与采集/推理应用。放弃首版可视化大平台和前端直接连接厂商 SDK。验证目标为 GUI/CLI 导出同一语义图后产生相同 plan/hash 与拒绝原因。
