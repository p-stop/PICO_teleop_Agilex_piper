# ADR-0009：A4-S graph、端点/批次分离与共享执行面

日期：2026-10-16。状态：accepted；真实运动映射/IK/backend仍待实现验证。关联[graph说明](../a4s-graph.md)、[计划006](../../plans/006-a4s-graph-and-shared-execution.md)。

## 决定

- A4-S保持双手柄控制双执行臂，底盘/升降固定；主从是可替换意图源，不因旧VR/IK体验欠佳就改掉用户当前目标。
- 本框架负责原始输入解释、相对映射、模型/FK/IK与执行仲裁；复用现有机器人ROS驱动作为设备边界，不启动旧VR/whole-body/IK控制链。
- 四逻辑端点（双臂rad、双夹爪m）与两个物理backend批次分开建模。先检查完整CommandSet，再按backend打包；全组软件准入不宣称硬件原子执行。
- teleop与模型在显式解码/运动转换之后汇入共同命令入口；输入、观测、动作空间和chunk调度的差异不强行抹平。关节策略不必经过IK。
- 源选择/长耗时求解前关联授权epoch；最终下发再次验证。迟到IK/策略结果保留原epoch，不以“完成时重新申请lease”恢复旧结果。
- 新多端点fake切片使用独立版本的配置/事件，不放宽M1固定拓扑或回放要求；不将合成joint mapper称为真实IK，不将fake采集等同真实遥操通过。
- 记录保留原始意图、运动输出、最终命令、receipt和反馈。流式结束hash/计数及必需流检查取代“清单文件存在就complete”。

## 原因与影响

旧系统已有驱动和实践数据，但其左右相机角色、10维移动单臂策略、整机尺寸、IK算法和时间假设不符合当前双臂静态目标。复用边界而非整包照搬，可以保留现场资产并测试框架共性。

第一版只实现一个执行组的fake垂直切片和可独立读回的采集；不是完整任意graph、分布式授权或真实IK。真实ROS网关/时钟watchdog、模型/标定和物理停止单独验收。采集证明共享底座，模型部署/任务效果仍要独立验证。
