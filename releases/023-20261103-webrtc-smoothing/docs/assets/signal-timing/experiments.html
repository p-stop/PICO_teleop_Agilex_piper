A · 采样与混叠

样本之间，究竟发生了什么？

教学正弦，幅值 1 rad。尝试 18 Hz 输入 / 30 Hz 采样，再把采样改成 60 Hz。负别名频率表示相位反向。此实验没有噪声、抖动或有限窗 sinc 重建。

B · 控制与记录解耦

记录得更快，机械臂就会跟得更好吗？

假设一阶执行器 dq/dt = 2πB(u−q)，初值为零，使用 1 ms 网格和分段常值输入精确积分。参考是 1 Hz 与 5 Hz 正弦之和。先只调“记录频率”：模拟运动不应变化。这里没有 IK 或真实 Piper 动力学。

延迟与低带宽改变实际响应；降采样与漏记改变我们知道多少。现实中记录过载也会争抢资源，本教学模型刻意隔离这一耦合。零间隙也不保证线性重建精确。

C · 推理时间预算

下一段动作，能赶在队列用完前到达吗？

这只是时序预算。RTC 还要在模型生成过程中利用旧计划前缀；“有异步线程和动作缓冲”本身不等于 RTC。首段动作预先就绪，启动阶段延迟未画入。
